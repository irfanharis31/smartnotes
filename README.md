# SmartNotes 📝

SmartNotes is a full-stack MERN-based notes management application built to help users efficiently create, organize, and retrieve digital notes across both personal and professional contexts.

## 🌟 Features

* Built using MongoDB, Express.js, React.js, and Node.js (MERN)
* Categorize notes as Work or Personal
* Mark notes as Favorites for quick access
* Powerful search by title, tags, or content
* Trash system to recover deleted notes
* Note locking for enhanced security
* Fully responsive UI built with Tailwind CSS
* Real-time interactions and smooth UX with React and GSAP
